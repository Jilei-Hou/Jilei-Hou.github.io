QDrop：随机丢弃量化，把 PTQ 推向 2-bit

本文介绍 arXiv:2203.05740《QDrop: Randomly Dropping Quantization for Extremely Low-bit Post-Training Quantization》（Wei、Gong、Li、Liu、Yu 等人，ICLR 2022）。它研究的是后训练量化（PTQ）在极低比特（例如 2-bit 权重 + 2-bit 激活，写作 W2A2）下的失效与解决方案。

QDrop 一句话结论： 在 PTQ 的逐块重建阶段，随机丢弃激活量化（默认丢弃概率 p = 0.5），让优化后的低比特权重在损失面上更平坦；由此把 PTQ 的可行下限从 4-bit 推进到 2-bit 激活，在 ImageNet W2A2 上相比 Brecq† 可提升约 12~51 个百分点。

论文速览

PTQ 指预训练模型离线完成量化、无需端到端微调，只用少量校准数据重建量化模型。AdaRound、Brecq 等方法通过 Taylor 展开把量化视为权重扰动来学习取整，在 4-bit 上有效，甚至把权重推到 2-bit。QDrop 进一步指出：激活量化也应进入重建，且部分引入优于全引入。

  • 论文：arXiv:2203.05740，Wei、Gong、Li、Liu、Yu 等人，ICLR 2022 论文。
  • 方法：QDrop，在 PTQ 重建中随机丢弃激活量化。
  • 核心结论：PTQ 首次可达 2-bit 激活；ImageNet W2A2 上相比 Brecq†，准确率最高提升 51.49 个百分点。

PTQ 为什么难做到极低比特

量化把权重和激活压缩到固定点，用于边缘设备。研究者通常把量化分为感知训练（QAT）和后训练量化（PTQ）。PTQ 只用校准数据重建，成本低；但极低比特激活量化仍难做到高准确率。

以 AdaRound、Brecq 为代表的方法看，它们把量化视为权重扰动 Δw，用 Taylor 展开学习取整，再通过重建层或 block 输出逼近全精度输出。这类方法在 4-bit 上有效，甚至把权重推到 2-bit。但它们只建模权重扰动，忽略了激活量化，因此极低比特激活下”同一个优化后的权重”不随激活位宽变化，显然反直觉，也导致结果欠佳。

the same optimized model no matter which bit the activations use, which is obviously counter-intuitive and thus causes a sub-optimal solution.

关键实验：三种激活量化引入方式

理论：为什么随机丢弃能提升低比特准确率

作者把激活量化看作注入噪声。传统写法是加法噪声 e=a^−ae = \hat{a} - ae=a^−a；为了去掉激活取值范围对噪声幅度的影响，论文把它改写成乘性形式：

a^=a⋅(1+u),u=a^a−1\hat{a} = a \cdot (1 + u), \qquad u = \frac{\hat{a}}{a} - 1a^=a⋅(1+u),u=aa^​−1

这样 u 的范围只由位宽和舍入误差决定。于是 PTQ 的目标从”只考虑权重扰动”变成同时考虑权重和激活噪声，对应论文式 (4)：

min⁡w^  Ex∼Dc[L(w+Δw,x,1+u(x))−L(w,x,1)]\min_{\hat{w}} \; \mathbb{E}_{x \sim \mathcal{D}_c}\left[ L(w + \Delta w, x, 1 + u(x)) - L(w, x, 1) \right]w^min​Ex∼Dc​​[L(w+Δw,x,1+u(x))−L(w,x,1)]

借助 Lemma 1，激活噪声可以等价吸收为权重扰动 v(x)v(x)v(x)（论文在附录 B.1/B.2 中分别对全连接层与卷积层给出证明）；把这一等价关系代入式 (4)，损失变化可拆成两项，即 Theorem 1 的式 (7)：

（7-1）是 AdaRound、Brecq 已经在优化的权重量化项；（7-2）是引入激活量化后多出来的损失变化，衡量模型在扰动 v(x) 下是否”平坦”：同样的扰动幅度，损失变化越小越平坦。

Corollary 1 进一步指出：在校准数据上引入激活量化噪声后，存在对应的权重扰动 v(x)，使优化后的量化模型更平坦。这解释了 Case 2/3 为什么优于 Case 1；但只在校准集上平坦可能过拟合，全量引入（Case 2）在测试集上反而不如部分引入（Case 3）。

QDrop 方法

QDrop 的思路：既然平坦性依赖数据分布与扰动方向，需要在更多方向上追求平坦；于是提出 QDrop，在 PTQ 重建中随机丢弃激活量化。定义（式 9）：以概率 p 丢弃量化（换回 FP32），以概率 1 - p 保留量化，默认 p = 0.5。

前面说的”随机丢弃”，用论文式 (9) 写出来是：

QDrop:u={0,with probability pa^/a−1,with probability 1−p\text{QDrop:}\quad u = \begin{cases} 0, & \text{with probability } p \\ \hat{a}/a - 1, & \text{with probability } 1 - p \end{cases}QDrop:u={0,a^/a−1,​with probability pwith probability 1−p​

也就是说，每个激活元素每次前向都有 p 的概率”绕过”量化（u = 0，用 FP32 值），否则走量化值；p = 0.5 时两种状态各占一半，熵最大，能覆盖更多扰动方向。

  1. 前向传播：对当前 block 输入与块内激活，按元素随机以概率 p 丢弃量化，换回全精度值。
  2. 反向传播：用重建输出与 FP32 块输出之差计算重建误差，对权重取整与激活步长做联合梯度下降。
  3. 完成后关闭丢弃，进入下一 block；推理时恢复为纯量化模型，无额外开销。

QDrop 是三种 Case 的统一归纳：p = 1 时退化为 Case 1（激活全程 FP32、只量化权重）；p = 0 时退化为 Case 2（激活全量量化）；前 k-1 个 block 以 p = 0（保留量化）、当前 block 以 p = 1（丢弃量化），即 Case 3。QDrop 是对 Case 3 的 element-wise 细粒化，无需再手动选择 Case。下图给出 QDrop、Case 1 与 Case 3 在测试数据上的损失曲面：QDrop 的曲面明显更平滑，说明它在更多扰动方向上保持平坦。

实验结果

在 ImageNet 分类实验中，QDrop† 相比 Brecq† 在 W2A2（2-bit 权重 + 2-bit 激活）上分别提升 12.18、29.66、51.49 个百分点（ResNet-18 / ResNet-50 / RegNet-3.2GF）。MobileNetV2 在 W3A3（3-bit 权重 + 3-bit 激活）上，QDrop† 可达 57.98%，而 Brecq† 为 23.41%。† 表示采用 Brecq 的首尾层设置：在常规首尾层 8-bit 的基础上，额外保留首层输出为 8-bit。下表汇总论文 Table 3 中 W2A2 与 W3A3 的关键结果（Top-1 准确率，%）。

扩展到其他任务：在 MS COCO 目标检测中，W4A4 下 Faster RCNN 的 mAP 接近全精度（差距约 1.2~2.6 个百分点）；RetinaNet 的 MobileNetV2 骨干网络相比 Brecq† 带来约 4.9 个百分点的 mAP 提升；W2A4 下提升更明显，RetinaNet 的 MobileNetV2 相比 Brecq† 最高约 +6.5 mAP。在 GLUE 与 SQuAD 的 BERT 任务（E8W4A4：embedding 8-bit，权重与激活 4-bit）中，QDrop 对比常规 PTQ（No Drop）提升显著，QNLI 约 +8.7、QQP 约 +4.6、RTE 约 +7.2 个百分点。

落地要点

  • 重建迭代：每个 block 或 layer 输出重建 20k 次。
  • 校准数据：ImageNet 1024 张、COCO 256 张、NLP 1024 个样本。
  • 量化配置：视觉任务首尾层保持 8-bit；NLP 任务 embedding 为 8-bit；权重按通道量化。

“随机丢弃”的实现细节： QDrop 不改变量化图结构，只在训练期给每个激活量化器加一个逐元素的伯努利掩码，核心只有一行：

两个位置会用到这个掩码：一是 block 输入，用 FP32 输入与量化输入按元素随机混合；二是 block 内部每个激活量化器的输出，同样按元素与 FP32 激活混合（见 recon.py 的 reconstruction 循环）。每个 block 重建完成后关闭丢弃，该 block 以全量化形式参与后续 block 的重建；推理阶段没有随机性，部署的就是普通量化模型。

注意代码里的 drop_prob 与论文的 p 互为补数：drop_prob 表示保留量化的比例；QDrop 取 p = 0.5，此时两者取值相同。额外开销只发生在校准阶段：需要同时缓存 FP32 与量化后的激活，并生成同形状掩码，前向计算量与原 PTQ 重建基本相同。

局限与讨论

  • 极低比特（W2A2）下，轻量网络的准确率仍明显偏低：MobileNetV2 仅 13.05%、MNasNet 28.77%（QDrop†，ImageNet Top-1）。
  • 理论依据部分基于一阶泰勒展开与 Lemma 1 的近似；平坦度证据主要来自 ResNet-18 W3A3 的损失曲面、sharpness 测量与 Hessian 统计。
  • 丢弃概率 p = 0.5 来自最大熵假设与少量消融；不同架构可能存在更优取值。
  • 方法间的结论受实验设置差异影响（如 AdaQuant 的量化节点插入方式、Brecq 的 † 首尾层设置）。
