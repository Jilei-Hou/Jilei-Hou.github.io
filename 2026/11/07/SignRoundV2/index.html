SignRoundV2

项目 内容
论文 SignRoundV2: Toward Closing the Performance Gap in Extremely Low-Bit Post-Training Quantization for LLMs
作者 Wenhua Cheng、Weiwei Zhang、Heng Guo、Haihao Shen（Intel），Zaner Ma（北京理工大学）
版本 arXiv:2512.04746。v1 发布于 2025-12-04，v2 修订于 2026-05-18，本文依据 v2
代码 intel/auto-round（Apache-2.0）
关键词 训练后量化（PTQ）、混合精度、W2A16、MXFP4、SignRound

速览

SignRoundV2 是 Intel 在 SignRound（下文称 V1）基础上提出的大模型训练后量化方法。它用逐层敏感度指标 DeltaLoss 自动分配混合位宽，并让 V1 的逐 block 调优在 2-bit、4-bit 下更稳定。量化成本仍在 PTQ 量级（Llama2-70B 单卡约 2.5 GPU 小时），70B 模型上的 2-bit 精度接近 AQLM、EfficientQAT 等需要大量训练的方法；纯 2-bit 下与全精度仍有差距。

两项核心改动

  • 自适应混合精度：DeltaLoss 用”梯度 × 量化误差”估计每层量化后损失会增加多少，再用动态规划在平均位宽预算内为每层选位宽。
  • 调优稳定化：调优前先做一次轻量的 scale 搜索作为初值；调优时丢掉最大的 0.1% 误差项，避免离群误差把量化参数带偏。

主要结果

  • MXFP4/6 混合，平均 4.5 bits：5 个模型与 16-bit 的平均准确率差距都在 1 个百分点以内（恢复率 98.6%–100.4%）。
  • 纯 2-bit 权重量化（W2A16）：GPTQ、AWQ 在 2-bit 下基本失效（Llama2-70B 上只有 34–35 分，原模型 72.41）。V2 在 Llama3-70B 上得到 69.02（V1 为 64.76），高精度配置得到 70.93，超过 AQLM 的 70.10。7B/8B 模型上仍落后 AQLM 2.8–3.7 个点。
  • 平均 2.5 bits 混合精度：4 个模型上都优于 AMQ 和 SFMP，Llama3.1-8B 的恢复率比 AMQ 高 12.24 个百分点。
  • 成本：Llama2-70B 做 W2A16 量化，V2 约 2.5 GPU 小时，EfficientQAT 为 41 小时，AQLM 为 336 小时。

背景：极低比特 PTQ 难在哪里

大模型解码阶段通常受显存容量和带宽限制，把权重压到 4 bit 以下可以直接减少显存占用和数据搬运。训练后量化（PTQ）不重新训练模型，只需少量校准数据，是落地时最常用的路线。量化感知训练（QAT）精度通常更高，但要几十到几百 GPU 小时，对训练数据分布敏感，还可能带来遗忘或过拟合。

PTQ 在两类设置下损失明显：

  • 2-bit 纯权重量化（W2A16）：常规 PTQ 基本失效。论文表 1 中，Llama2-70B 用 GPTQ 或 AWQ 量化到 2 bit 后，5 个任务的平均准确率只有 34%–35%，原模型为 72.41%。
  • 4-bit 权重 + 激活量化（如 MXFP4）：激活中的离群值会放大误差。用最简单的就近舍入（RTN）把 Llama3.1-8B-Instruct 量化成 MXFP4，只能保留 90.88% 的精度。

混合精度是常见的补救办法：敏感的层多给 bit，不敏感的层少给。难点在于怎样又准又快地衡量每层的敏感度，已有做法各有短板：

  • 基于 Hessian 或 Fisher 信息的二阶指标（如 HAWQ）假设模型处在局部最优点、梯度近似为 0，量化扰动较大时这个假设不成立；对数十亿参数的模型，二阶计算的开销也很大。
  • 强化学习或 AutoML 搜索（如 HAQ、AMQ）能自动分配位宽，但搜索本身很慢。
  • llama.cpp 等框架用经验规则分配位宽，换一种数据类型或模型结构往往要重新设计规则。

先回顾 SignRoundV1

V1 按 Transformer block 逐个处理：以全精度 block 的输出为目标，用符号梯度下降（只用梯度的符号更新参数）学习三个量化参数，让量化后 block 的输出尽量接近原输出。量化过程写成：

QDQ(W)=s⋅clip(⌊Ws+v⌉,n,m),s=max⁡(W)⋅α−min⁡(W)⋅β2bit−1\mathrm{QDQ}(W)=s\cdot\mathrm{clip}\left(\left\lfloor\frac{W}{s}+v\right\rceil,n,m\right),\qquad s=\frac{\max(W)\cdot\alpha-\min(W)\cdot\beta}{2^{\mathrm{bit}}-1}QDQ(W)=s⋅clip(⌊sW​+v⌉,n,m),s=2bit−1max(W)⋅α−min(W)⋅β​

其中 vvv 决定每个权重向上还是向下舍入，α\alphaα、β\betaβ 调整截断范围。V1 在 2-bit 下已经明显好于 GPTQ、AWQ（Llama2-70B 上 67.70 对 34.38、35.49），但与全精度和 QAT 类方法仍有距离。SignRoundV2 在这个框架上做改进。

方法

SignRoundV2 分两个阶段：先用 DeltaLoss 决定每层用几 bit，再沿用 V1 的框架逐 block 调优，并加入 scale 预搜索和损失过滤两个稳定化手段。

DeltaLoss：估计量化带来的损失增量

二阶指标只能反映敏感度的相对趋势。DeltaLoss 换了个思路，直接估计”某层量化后整体 loss 会涨多少”。记某层全精度与量化后的激活为 AfA_fAf​、AqA_qAq​，权重为 WfW_fWf​、WqW_qWq​，在量化点做一阶泰勒展开：

ΔL=Lq−Lf≈gA⊤(Aq−Af)+gW⊤(Wq−Wf)\Delta\mathcal{L}=\mathcal{L}_q-\mathcal{L}_f\approx g_A^{\top}(A_q-A_f)+g_W^{\top}(W_q-W_f)ΔL=Lq​−Lf​≈gA⊤​(Aq​−Af​)+gW⊤​(Wq​−Wf​)

梯度 gAg_AgA​、gWg_WgW​ 在量化后的模型上用少量校准数据计算。直接求和时正负项会互相抵消，所以论文改用逐元素乘积的绝对值之和作为敏感度分数，并在校准样本上取平均：

DeltaLoss=∥gA⊙(Aq−Af)∥1+∥gW⊙(Wq−Wf)∥1\mathrm{DeltaLoss}=\left\|g_A\odot(A_q-A_f)\right\|_1+\left\|g_W\odot(W_q-W_f)\right\|_1DeltaLoss=∥gA​⊙(Aq​−Af​)∥1​+∥gW​⊙(Wq​−Wf​)∥1​

量化误差大、梯度也大的层得分高，在同样的位宽预算下会优先拿到高位宽。权重和激活使用相同位宽时（如 MXFP 场景），激活量化通常是主要误差来源，默认只保留激活项。计算 DeltaLoss 只需要 16 条长度为 256 的校准样本。

论文图 2 展示了 Llama-3.1-8B-Instruct 的逐层 DeltaLoss：横轴是第 0–31 个 block，纵轴是 block 内的 7 个线性层，颜色越深越敏感。从图中可以看出两点：

  • 同一个模型换一种数据类型，敏感层的分布就变了。W2A16 下敏感层集中在前半部分 block 的 o_proj、gate_proj、up_proj、down_proj；MXFP4 下 down_proj 在几乎所有 block 中都最敏感。为每种格式手写分配规则既费力，效果也不一定好。
  • 同一个 block 内各层差别很大：down_proj 一直偏敏感，q_proj、k_proj 普遍不敏感。把整个 block 回退到高精度会浪费位宽，按层分配更合适。

有了每层在每个候选位宽下的 DeltaLoss，位宽分配就是一个带预算的组合优化：每层从候选位宽集合 BBB（如 INT2/INT4，或 MXFP4/MXFP6）中选一个，使所有层的 DeltaLoss 之和最小，同时按参数量加权的平均位宽不超过目标 TTT：

其中 Ii,b∈{0,1}I_{i,b}\in\{0,1\}Ii,b​∈{0,1} 表示第 iii 层是否选位宽 bbb，PiP_iPi​ 是该层参数量。这本质上是一个分组背包问题，用动态规划或整数线性规划即可求解。位宽按整层（per-tensor）分配，不在层内混用，部署时对 kernel 更友好。

损失过滤

逐 block 调优的目标是量化 block 输出与全精度 block 输出之间的均方误差（MSE）。在极低比特下，少数元素的误差特别大，它们产生的大梯度会把量化参数带偏。V2 在每个 batch 中剔除逐元素误差最大的 kkk 项（kkk 取元素总数的 0.1%），只对剩余部分求平均：

实验结果

实验设置

  • 模型：Llama 2（7B/13B/70B）、Llama 3（8B/70B）、Llama 3.1（8B、8B-Instruct、70B-Instruct）、Qwen2.5-7B-Instruct、Qwen3（8B/14B/32B）。
  • 评测：用 lm-evaluation-harness 做零样本评测。任务取自 ARC-Challenge、ARC-Easy、BoolQ、HellaSwag、LAMBADA、MMLU、OpenBookQA、PIQA、TruthfulQA、WinoGrande，不同实验分别报告 5、6 或 10 个任务的平均准确率。

局限与适用边界

作者列出的局限

  • 纯 2-bit 下与全精度仍有明显差距，极低比特 PTQ 还离不开混合精度或额外训练。
  • 位宽在调优前一次性确定，调优过程中不再改变。把位宽分配和舍入参数联合优化可能更好，但搜索复杂度会上升。
  • DeltaLoss 需要计算梯度，无法直接用在 ONNX Runtime 这类只支持推理的框架中。

阅读时值得注意的地方

  • 评测范围：全部是 lm-eval 零样本任务，以选择题为主，没有数学推理、代码、长文本生成或对话质量的评测。auto-round 文档补充了 W2G64 下 GSM8K、MMLU-Pro 等任务的结果，可作参考。
  • 位宽口径：除表 2 等特别说明处外，论文的平均位宽都不含 scale 和零点。以 G128 为例，若每 128 个权重共享一个 16-bit 的 scale，每个权重实际多占 0.125 bit。
  • MXFP 基线：MXFP 实验只和 RTN、V1 比较，没有与旋转类方法（如 QuaRot、SpinQuant）等其他权重 + 激活量化方案对比。论文给出的理由是多数 PTQ 方法不支持 MX 格式、缺少可比的基线，并在相关工作中提到旋转类方法会增加推理开销。
  • 推理速度：论文没有报告推理延迟或吞吐。实际收益取决于推理框架对所选格式（尤其是逐层混合位宽和 MXFP4）的 kernel 支持，部署前需要确认。
  • 模型覆盖：实验只覆盖 Llama 和 Qwen 的稠密模型，最大 70B，没有 MoE 模型。

代码与复现

官方实现在 intel/auto-round，以下信息摘自其 README 和文档：

  • V2 的调优改进通过 --algorithm auto_round_v2 开启（旧参数名为 enable_alg_ext），混合精度方案通过 AutoScheme 生成。
  • README 推荐：W4A16 用默认的 auto-round 配方；W2A16 用 auto-round-best 配方并加上 --algorithm auto_round_v2。
  • 用较新版本的 Transformers 评测 Llama 模型时，文档建议去掉 modeling_llama.py 中的 @use_kernel_forward_from_hub("RMSNorm")，并在 lm-eval 中开启 add_bos_token，以稳定量化模型的精度。

AutoScheme 的 API 用法如下（摘自 auto-round 文档）。传入多个候选方案即开启 AutoScheme，bits 为目标平均位宽；iters=0 是基于 RTN 的快速模式，iters=200 会结合调优来选方案，更准但慢得多。
