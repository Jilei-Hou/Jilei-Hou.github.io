OmniQuant

算法原理

权重量化通常使用 min-max 方式，取权重张量的最小值和最大值作为量化边界，这种做法存在一个问题：权重中的离群值会拉大量化范围，导致大部分正常权重被分配到过少的量化级别上。

LWC（Learnable Weight Clipping，可学习权重裁剪）引入了两个可学习参数 γ\gammaγ 和 β\betaβ 对权重的最大、最小值做裁剪。

Wq=clamp(⌊Wh⌉+z, 0, 2N−1)W_\mathbf{q} = \text{clamp}\left(\left\lfloor \frac{\mathbf{W}}{h} \right\rceil + z,\ 0,\ 2^N - 1\right)Wq​=clamp(⌊hW​⌉+z, 0, 2N−1)

h=γmax⁡(W)−βmin⁡(W)2N−1,z=−⌊βmin⁡(W)h⌉h = \frac{\gamma \max(\mathbf{W}) - \beta \min(\mathbf{W})}{2^N - 1}, \quad z = -\left\lfloor \frac{\beta \min(\mathbf{W})}{h} \right\rceilh=2N−1γmax(W)−βmin(W)​,z=−⌊hβmin(W)​⌉

其中 γ=Sigmoid(tγ)∈[0,1]\gamma = \text{Sigmoid}(t_{\gamma}) \in [0, 1]γ=Sigmoid(tγ​)∈[0,1]，β=Sigmoid(tβ)∈[0,1]\beta = \text{Sigmoid}(t_{\beta}) \in [0, 1]β=Sigmoid(tβ​)∈[0,1]，初始值 γ=1,β=1\gamma = 1, \beta = 1γ=1,β=1，基于梯度自动更新：

  • 前向传播：使用当前的 γ\gammaγ 和 β\betaβ 计算裁剪阈值，对权重模拟量化，得到 Block（decoder layer）的量化输出；
  • 反向传播：计算 Block 量化输出和浮点输出的 MSE，通过 STE 技巧（梯度跨过不可导的 Round）更新 tγ,tβt_{\gamma}, t_{\beta}tγ​,tβ​。
