SignRound：用符号梯度下降优化大模型量化的权重舍入

一句话看懂： SignRound 是一种训练后量化（PTQ）方法。它不改动原始权重，只为每个权重学习一个取整偏移 V，并为截断范围学习两个系数 α、β；以 Transformer block 的输出误差为目标，用符号梯度下降（SignSGD）每个 block 只调 200 步。量化完成后模型仍是普通的整数权重加量化参数，推理没有额外开销。

效果： 在 W2G128（2-bit 权重、每 128 个权重共享一组量化参数）下，Mistral-7B 和 LLaMA-V2 系列在 11 个零样本任务上的平均准确率比 RTN、GPTQ、AWQ、HQQ、OmniQuant 高 6.91～33.22 个百分点；4-bit 在多数模型上接近无损。

论文要解决什么问题

大模型部署的主要障碍之一是显存和存储占用。生成 token 时，速度往往受限于显存带宽而不是算力；激活量化本身难度又更大。因此只压缩权重、激活保持 16 位的仅权重量化，是更务实的选择。

现有量化路线各有短板，SignRound 想取两者之长：

路线 做法 优点 代价
量化感知训练（QAT） 训练时模拟低精度，让模型适应量化误差 准确率通常更高 训练复杂、耗时长、要调超参，用在 LLM 上资源消耗大
训练后量化（PTQ） 直接量化训练好的模型，最多使用少量校准数据 简单、成本低 低比特下准确率下降明显
SignRound 在 PTQ 框架内轻量调优：逐 block 用少量校准数据调 200 步，只学习舍入和截断参数 作者定位为兼顾 QAT 的准确率与 PTQ 的成本 需要校准数据和反向传播，比免校准方法慢

论文的切入点是舍入（rounding）。最常用的就近取整（RTN）对每个权重独立四舍五入，忽略了权重之间、权重与激活之间的相关性。AdaRound 曾把舍入建模为二次无约束二值优化，并用二阶泰勒展开近似损失；但取整结果还要乘上量化 scale，权重变化可能不小，只保留二阶项未必准确。FlexRound 更灵活，但需要针对每个模型和任务调专门的超参，难以扩展到 LLM。

方法：只学三类参数，用梯度符号去调

在量化公式里加入 V、α、β

标准的非对称量化先按权重范围算出 scale，再就近取整：

W~=s⋅clip(⌊Ws+zp⌉,n,m),s=max⁡(W)−min⁡(W)2bit−1\widetilde{W} = s \cdot \mathrm{clip}\left(\left\lfloor \frac{W}{s} + zp \right\rceil, n, m\right), \quad s = \frac{\max(W) - \min(W)}{2^{bit} - 1}W=s⋅clip(⌊sW​+zp⌉,n,m),s=2bit−1max(W)−min(W)​

SignRound 在取整前加入逐元素的偏移 V，并用 α、β 缩放权重的最大值和最小值：

W~=s⋅clip(⌊Ws+zp+V⌉,n,m),s=max⁡(W)⋅α−min⁡(W)⋅β2bit−1\widetilde{W} = s \cdot \mathrm{clip}\left(\left\lfloor \frac{W}{s} + zp + V \right\rceil, n, m\right), \quad s = \frac{\max(W) \cdot \alpha - \min(W) \cdot \beta}{2^{bit} - 1}W=s⋅clip(⌊sW​+zp+V⌉,n,m),s=2bit−1max(W)⋅α−min(W)⋅β​

  • V（舍入偏移）：与权重同形状，初始为 0，取值限制在 [-0.5, 0.5]。每个权重最终只会在”向下取整”和”向上取整”两个整数之间二选一，相当于为每个权重决定舍入方向。
  • α、β（截断系数）：取值 [0, 1]，初始为 1，分别缩放 max(W) 和 min(W)，用来学习更合适的截断范围，思路沿用 AWQ、OmniQuant 的权重截断调优。

优化目标是 block 级的输出重建：用同一批输入分别跑原始 block 和伪量化 block，让两者输出尽量一致：

这里的 block 指什么： 一个 Transformer block（层）通常包含多头自注意力（MHA，含 Q/K/V 和输出投影）和前馈网络（FFN，两个线性层加激活函数），以及配套的残差连接和归一化层（LayerNorm 或 RMSNorm）。SignRound 把这样一个完整结构当作优化单元：固定输入 X（上一层的输出），分别用原始权重和伪量化权重跑该 block 的前向，以两者输出的 MSE 为损失，然后逐 block 依次处理整个模型。

min⁡α,β,V∥WX−W~X∥F2\min_{\alpha, \beta, V} \left\| WX - \widetilde{W}X \right\|_F^2α,β,Vmin​​WX−WX​F2​

其中 X 是 block 的输入。原始权重 W 全程不变；调优结束后，V 只影响取整结果，α、β 只影响 scale 等量化参数，最终产物与普通整数量化模型的格式一致，所以推理没有额外开销。

为什么用 SignSGD 而不是 Adam

SignSGD 只用梯度的符号更新参数，每一步的步长就是学习率：

θt+1=θt−lrt⋅sign(gt)\theta_{t+1} = \theta_t - lr_t \cdot \mathrm{sign}(g_t)θt+1​=θt​−lrt​⋅sign(gt​)

论文给出四点理由：

  1. 只有越过阈值才有意义：取整结果只在 W/s + zp + V 越过取整阈值时才改变，最优的 V 通常是一段区间而不是一个精确值，不需要梯度幅值精确收敛。
  2. 搜索空间有界：V 在 [-0.5, 0.5]，α、β 在 [0, 1]，固定步长能在有限步数内有效覆盖这个空间；Adam 受梯度幅值大幅波动影响，很难在 200 步内收敛到最优值。
  3. 步长直观，几乎不用调参：默认 200 步、学习率 5e-3、线性衰减，除特别说明外全部实验共用这组设置。线性衰减下所有步长之和约为 200 × 0.005 / 2 = 0.5，正好让 V 从 0 出发覆盖 [-0.5, 0.5]，让 α、β 从 1 出发覆盖 [0.5, 1.0]。
  4. 开销小：不需要保存 Adam 的一阶、二阶矩状态，显存和计算都更省。

算法流程

SignRound 按顺序逐个处理 Transformer block，只量化 block 内的线性层，embedding 和 lm_head 不量化。下图是单个 block 的调优循环：

MoE 模型与 router 量化： AutoRound 支持 MoE 模型（论文实验涵盖 Mixtral-8x7B 和 Mixtral-8x7B-Instruct），默认会量化 block 内的所有线性层，包括 router（即 gate 层，负责将 hidden state 映射到 num_experts 维的路由权重）。由于 router 是参数量极小的线性层，但对路由决策非常敏感，实践中建议通过 layers_to_skip 参数将各 MoE block 的 router/gate 层排除在量化之外，对整体压缩比影响极小，却能显著避免路由崩塌风险。

对应论文 Algorithm 1，每个 block 的步骤如下：

  1. 取当前 block 的输入 X（即前一个 block 的输出），每步随机抽 8 条校准样本。
  2. 分别用原始权重和伪量化权重（量化后立即反量化）做前向，得到 y_f 和 y_q。
  3. 计算 MSE(y_q, y_f) 并反向传播。
  4. 如果本步 loss 低于历史最低值，记录当前的 V、α、β。
  5. 用 SignSGD 更新 V、α、β，回到第 1 步，共循环 200 步。
  6. 用记录下的最优参数把该 block 的权重量化为整数，再处理下一个 block。

实验结果

实验设置

模型 LLaMA-V1（7B / 13B / 30B / 65B）、LLaMA-V2（7B / 13B / 70B）、Mistral-7B-v0.1；泛化实验另测 Gemma、Phi-3、Mixtral、Llama-3 等

比特数升高后，各方法的差距明显收窄：

  • W4G128：所有方法与 16 bit 原模型的差距都不超过 1.2 分，SignRound 最多领先零点几分，也不是每格最优，例如 LLaMA-V2-13B 上 GPTQ 为 61.00，SignRound 为 60.85。
  • W4G-1（不分组，更难）：Mistral-7B 上 RTN 下降 4.46 分，SignRound 只下降 0.97 分；LLaMA-V2-70B 上 AWQ（66.28）与 SignRound（66.27）基本持平。
  • W3G128：SignRound 在 4 个模型中的 3 个上领先最强基线 0.2～1.5 分，LLaMA-V2-13B 上默认配置（59.44）略低于 GPTQ（59.58）。

按胜负统计，在 LLaMA-V1、LLaMA-V2、Mistral-7B 共 8 个模型 × 4 种配置的 32 组对比中，SignRound 优于 GPTQ 30 组、AWQ 27 组、OmniQuant 29 组；与 HQQ 对比的 16 组中优于 15 组。

读表提示： SignRound* 是每个模型在 8 组超参（步数 200 / 1000、截断参数学习率 1.0/steps 或 2.0/steps、是否用量化后的前序 block 输出作为输入）中取最高分的结果（70B 只试了其中几组），相当于按评测成绩挑选配置。公平比较时建议以默认配置的 SignRound 为准。

对比其他舍入方法和优化器

对比 AdaRound / FlexRound： 200 步的 SignRound 在 W4G-1 上与 5000 步的 FlexRound 持平或更好（Mistral-7B 62.33 vs 60.94，LLaMA-V2-7B 57.48 vs 57.49）；W2G128 下 AdaRound 和 FlexRound 都停在 30～32 分，SignRound 为 48.64～53.46 分。同样跑 200 步量化 LLaMA-2-7B，SignRound 约 1041 秒，另两者约 9600～9700 秒；作者也说明，这两者用的第三方实现缺少 AMP 等优化。

SignSGD 对比 Adam： Adam 在 2.5e-3～2e-2 的 8 个学习率中取最好成绩，SignSGD 固定使用 5e-3。6 组对比全部是 SignSGD 更高，2-bit 下差距更大；而且 Adam 的最佳学习率随模型和配置在 2.5e-3～1.75e-2 之间变化，需要逐个搜索。

舍入调优 vs 截断调优： 两者单独使用大多优于 RTN，舍入调优贡献更大。W2G128 下 Mistral-7B 从 RTN 的 30.52 提升到只调舍入的 52.32，只调截断为 46.60，两者都调为 52.71；但在 LLaMA-V2-7B / 13B 上，两者都调（48.64 / 53.46）反而略低于只调舍入（49.14 / 54.41）。

超参敏感性： 在 W4G-1 下分别改动校准序列长度（512）、样本数（128）、batch size（4）、步数（100 / 1000）、学习率（1e-2），平均分相对默认配置的变化约在 -2.0～+0.4 分之间，默认配置整体最均衡。

局限与适用边界

  • 2-bit 仍有明显差距： W2G128 下 Mistral-7B 平均分 52.71，比原模型低 10.59 分。作者认为可借助非均匀量化和混合精度继续缩小差距；后续的 SignRoundV2 就引入了自适应混合精度（见文末链接）。
  • 只做仅权重量化： 激活保持 16 位，收益主要在显存占用和带宽。论文没有给出推理速度测试，实际加速取决于推理框架的低比特 kernel。
  • 需要校准数据和调优时间： 每个 block 都要做前向和反向传播，70B 模型约需 2.5 小时。如果追求分钟级量化或拿不到校准数据，HQQ、RTN 这类免校准方法更合适。
  • 评测以零样本准确率为主： 困惑度只作参考，没有覆盖长文本生成、代码、数学推理等场景，用于这些任务前建议自行验证。
  • 并非每个配置都最优： 例如 LLaMA-V1-7B 的 W2G128 上 OmniQuant（43.68）高于 SignRound（41.80）；4-bit 下各方法的差距本来就很小。

开源实现：AutoRound

论文代码开源在 intel/auto-round（Apache-2.0）。截至 2026 年 11 月，它已发展为通用的大模型训练后量化工具包：

  • 核心算法是 SignRound，并集成了后续的 SignRoundV2、AutoScheme 混合比特方案生成等能力。
  • 支持 W4A16、W2A16 等整数方案，以及 MXFP4、NVFP4、FP8 和 GGUF；可导出 AutoRound、AutoGPTQ、AutoAWQ、GGUF 等格式。
  • 已接入 Transformers、vLLM、SGLang，可部署在 Intel CPU / XPU、Gaudi 和 NVIDIA GPU 上。
