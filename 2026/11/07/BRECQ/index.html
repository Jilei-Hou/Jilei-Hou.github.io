BRECQ：用块重建推进后训练量化到 INT2

论文背景与读者指引

用 1024 张校准图做块级重建，后训练量化（PTQ）首次能在 INT2 下保持可用精度，且 4-bit 效果与量化感知训练（QAT）相当，训练成本反而只有 QAT 的约 1/240。

本文介绍 Li 等（ICLR 2021）的论文 BRECQ: Pushing the Limit of Post-Training Quantization by Block Reconstruction。文章先交代背景和读者定位，再介绍论文的核心思想、方法、实验和局限。

为什么需要 BRECQ：PTQ 为何在低比特下崩溃

大模型部署中，量化是压缩模型、降低内存和算力的重要手段。常见流程先训练全精度模型，再量化感知训练（QAT）或直接做后训练量化（PTQ）。

维度 PTQ QAT
训练数据 仅小校准集（如 ImageNet 用 1024 张） 全量训练数据 + 端到端微调
训练算力 分钟级（如 ResNet-18 单卡约 20 分钟） 百 GPU 小时量级
隐私 不依赖完整训练数据 需要真实数据
精度 低比特（尤其 ≤ 2-bit 权重）下大幅崩溃 精度较好，但成本高

在仅量化权重、保留全精度激活的低比特场景下，方法（如 AdaRound、AdaQuant）的效果在 4-bit 尚可，但在 2-bit 权重时几乎崩溃。根本原因：就近取整（round-to-nearest）主要在参数空间最小化误差，而不是在任务损失上最小化——两者不同。

AdaRound 用泰勒展开把量化扰动对损失的影响近似为：

E[L(w^)−L(w)]≈12ΔwTHΔwE[L(\hat{\mathbf{w}}) - L(\mathbf{w})] \approx \frac{1}{2}\Delta\mathbf{w}^{T} \mathbf{H} \Delta\mathbf{w}E[L(w^)−L(w)]≈21​ΔwTHΔw

其中 H\mathbf{H}H 是权重扰动的 Hessian。由于预训练模型已收敛、梯度趋近于零，量化误差主要体现在二阶项。但完整 Hessian 计算代价高，AdaRound 做了两个简化：层间独立、预激活 Hessian 为常数对角阵，于是损失可约化为逐层重建输出误差。

核心思想：把重建单位从「层」升级到「块」

从层级到块级：跨层依赖不可忽略

层级重建假设层间独立，忽略了 Hessian 的非对角项。当扰动 Δw\Delta\mathbf{w}Δw 增大到 2-bit 级别时，该假设失效——跨层依赖变得显著，逐层最小化不再合适。

BRECQ：用块重建平衡二阶误差

BRECQ 将「重建什么」从单层扩展到 CNN 的残差块（block）。通过 Gauss-Newton 矩阵近似，把二阶误差优化转化为对网络最终输出的加权误差，等价于一个更通用的「蒸馏式」重建；但全网输出重建在仅有 1024 张校准图时容易过拟合，于是选择块内重建来缓解泛化问题。

方法：Fisher 加权 + AdaRound 取整 + 混合精度

选择块粒度

消融实验表明：块级（block-diagonal Hessian）重建在 ResNet-18 / MobileNetV2 上效果最好；跨层依赖主要集中在块内，残差连接强化了块内耦合；更大粒度（stage / net）泛化误差更大。

Fisher 信息加权的块输出重建

用对角 F\mathbf{F}F（Fisher Information Matrix，其对角元等于梯度平方）替代预激活 Hessian，得到加权块输出误差：

min⁡w^E[(ΔzT)H(Δz)]=min⁡w^E[(ΔzT)diag((∂L∂z1)2,…)(Δz)]\min_{\hat{\mathbf{w}}} \mathbb{E}[(\Delta\mathbf{z}^{T}) \mathbf{H} (\Delta\mathbf{z})] = \min_{\hat{\mathbf{w}}} \mathbb{E}[(\Delta\mathbf{z}^{T}) \mathrm{diag}\left((\frac{\partial L}{\partial z_1})^{2}, \ldots\right) (\Delta\mathbf{z})]w^min​E[(ΔzT)H(Δz)]=w^min​E[(ΔzT)diag((∂z1​∂L​)2,…)(Δz)]

其中 Δz=z−z^\Delta\mathbf{z} = \mathbf{z} - \hat{\mathbf{z}}Δz=z−z^ 是量化前后的块输出差异，g=∂L∂zg = \frac{\partial L}{\partial z}g=∂z∂L​ 用于加权。

这里 ggg 不单独出现在目标函数中：公式右侧 diag 矩阵的对角元 (∂L∂zi)2(\frac{\partial L}{\partial z_i})^{2}(∂zi​∂L​)2 正是 ggg 各分量的平方，即 F=diag(g12,…,gk2)\mathbf{F} = \mathrm{diag}(g_1^{2}, \ldots, g_k^{2})F=diag(g12​,…,gk2​)。因此 ggg 的作用是构造 Fisher 加权矩阵——梯度更大的输出维度对任务更敏感，获得更高权重。

Fisher Information Matrix（FIM）衡量模型对数据变化的敏感度，其对角元对应各输出维度上梯度的平方 (∂L∂zk)2(\frac{\partial L}{\partial z_k})^2(∂zk​∂L​)2；这使二阶误差加权限感知的任务损失加权。

替换完整预激活 Hessian 的原因在于：完整 Hessian 计算与存储成本高，diagonal FIM 可由校准梯度直接得到，在小校准集条件下计算更可行。

权重取整与激活步长

权重：沿用 AdaRound 的自适应取整（软取整后固化为硬取整）。激活：沿用 LSQ 的学习步长方法。论文将两者的优化目标统一到同一个块重建流程。

混合精度（mixed precision）

对不同层分配 2 / 4 / 8-bit 位宽，在硬件预算（模型大小 / 延迟）下最小化损失。BRECQ 将层间敏感度纳入块内重建，通过遗传算法（GA）搜索位宽配置。

实验结果

ImageNet 权重量化：关键数据

方法 精度 ResNet-18 ResNet-50 MobileNetV2
Full Precision 32/32 71.08 77.00 72.49
AdaRound* 2/32 55.96 47.95 32.54
AdaQuant* 2/32 0.30 0.49 0.11
BRECQ（Ours） 2/32 66.30 72.40 59.67
BRECQ（Ours） 4/32 70.70 76.29 71.66

带 * 表示论文作者基于开源代码的复现结果。32/32 表示权重与激活均为全精度。BRECQ 在 2-bit 下将 ResNet-18 Top-1 从 0.3（AdaQuant）提升到 66.30，并优于 AdaRound；在 4-bit 下达到 70.70。

与其他方法的关系

BRECQ 延续了 AdaRound、AdaQuant、Bit-Split 的逐层/逐块重建思路，但把重建粒度从层级变为残差块，并引入 Fisher 加权。QDrop（ICLR 2022）进一步在 BRECQ 的代码基础上加入了激活随机丢弃，把 PTQ 的极低比特能力推向 2-bit 激活。

局限与适用边界

  • 实验主要在 CNN（ResNet / MobileNetV2 / RegNet / MnasNet）及目标检测任务上；Transformer / NLP 未充分验证。
  • 混合精度的延迟测量基于自研 FPGA 模拟器与 ARM CPU 低比特 GEMM；部分硬件限制未覆盖。
  • 激活量化仅到 4-bit；2-bit 激活（如 QDrop 的工作）是后续研究。
  • 块粒度选择在论文中更多是实验性结论，未证明理论最优。

开源代码与使用

仓库：github.com/yhhhli/BRECQ（PyTorch，ICLR 2021 实现）。提供预训练模型（torch.hub 加载）与多卡分布式重建脚本。

总结

BRECQ 通过「块级重建 + Fisher 加权 + AdaRound/LSQ 混合优化 + 混合精度 GA 搜索」，首次将 PTQ 推向 INT2 可用水平，同时保持了与 QAT 相当的精度（4-bit 场景）与显著更低的训练成本。其思想对 LLM 量化等无明确「块」结构的场景仍有启发。
