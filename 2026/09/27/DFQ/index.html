DFQ

论文速览

项目 内容
标题 Data-Free Quantization Through Weight Equalization and Bias Correction
作者/机构 Markus Nagel, Mart van Baalen, Tijmen Blankevoort, Max Welling（Qualcomm AI Research）
出处 ICCV 2019，arXiv:1906.04721
方法简称 DFQ (Data-Free Quantization)
核心目标 把 FP32 模型直接转 INT8，无需数据 / 微调 / 调参，一个 API 调用完成

论文最有影响力的贡献之一是提出了量化方案分级（Quantization Levels），用于衡量一个量化方法的实际可用性：

级别 需要数据 需要反向传播 说明
Level 1 否 否 只看权重，一个 API 调用即可（DFQ 属于此级）
Level 2 是 否 用数据重算 BN 统计或逐层 loss，无需训练 pipeline
Level 3 是 是 需完整训练 pipeline 微调（如 QAT）
Level 4 是 是 需改架构或从头训练，仅适用特定模型

要解决的问题

许多 FP32 模型量化到 INT8 精度损失很小，但像 MobileNetV2 这类模型会灾难性掉点（论文中从 71.72% 掉到 0.12%）。作者定位到两个根因：

💡 问题一：权重通道间 range 差异过大
depthwise 层不同输出通道的权重范围差异巨大（如一个通道 [-128,128]，另一个 [-0.5,0.5]）。共享一套 per-tensor 量化参数时，小范围通道的权重全被量化成 0，信息丢失。
这也解释了为何 per-channel 量化明显更优。

💡 问题二：量化误差是有偏的
文献常假设量化误差无偏、会相互抵消，但实际上权重量化会给输出引入有偏误差 E[ỹ−y]，使下一层输入分布整体偏移。
depthwise 层每个输出通道只有 9 个权重，尤其严重。

DFQ 的三个步骤正是分别针对这两个问题：CLE + Bias Absorption 解决问题一，Bias Correction 解决问题二。

核心方法：三步走

DFQ 在常规量化之上增加三步。整体流程为：跨层均衡 → 偏差吸收 → 量化 → 偏差校正。

跨层范围均衡 Cross-Layer Equalization (CLE)

利用 ReLU 的正缩放等变性：f(sx)=s⋅f(x)f(sx) = s \cdot f(x)f(sx)=s⋅f(x)（s≥0，可推广到分段线性激活）。对相邻两层，可在不改变 FP32 输出的前提下重参数化：把第一层某通道的缩放因子转移到第二层对应输入通道抵消。

目标是让各通道 range 尽量一致（最大化每通道精度）。论文推导出最优缩放因子：

si=1ri(2)ri(1)ri(2)s_i = \frac{1}{r_i^{(2)}}\sqrt{r_i^{(1)} r_i^{(2)}}si​=ri(2)​1​ri(1)​ri(2)​​，使得两层对应通道 range 完全匹配，量化误差在两层间均摊。多层时迭代到收敛。

💡 说明：CLE 是一项纯”权重侧”技术，且完全不依赖校准数据。
• 改的是权重：CLE 直接改写相邻两层的权重张量（W^(1)=S−1W(1)\hat{W}^{(1)} = S^{-1}W^{(1)}W^(1)=S−1W(1)、W^(2)=W(2)S\hat{W}^{(2)} = W^{(2)}SW^(2)=W(2)S，外加 b^(1)=S−1b(1)\hat{b}^{(1)} = S^{-1}b^{(1)}b^(1)=S−1b(1)），激活本身不动，靠缩放等变性保证 FP32 输出不变。
• 依据也是权重：缩放因子只由两层的权重 per-channel range（r(1),r(2)r^{(1)}, r^{(2)}r(1),r(2)）算出，从权重里直接读取，无需跑任何数据。这正是 DFQ 归为 Level 1（data-free）的原因。
• 紧随其后的 Bias Absorption 用到的 β、γ 是 BN 已存的参数（非数据统计量），因此在含 BN 的常规 CNN 上，CLE + 吸收整体仍是 data-free；仅当模型无 BN 需用数据估计激活分布时，才会降为 Level 2。

💡 一句话：S 是等价变换群里的一个自由度，网络输出对它严格不变；CLE 就是在这个自由度里挑一个让权重通道 range 最均匀的点，让廉价的 per-tensor 量化逼近 per-channel 精度。

③ 为什么输出不变（维度视角）。层1权重形状 [out1,in1]，第 i 行是输出神经元 i，乘 1/si1/s_i1/si​ 使其输出缩小 s_i 倍、range 改变；层2权重形状 [out2,in2]（in2=out1），第 i 列对应输入通道 i，乘 sis_isi​ 正好补偿。关键在 ReLU 与正缩放可交换（ReLU(x/si)=ReLU(x)/si\mathrm{ReLU}(x/s_i) = \mathrm{ReLU}(x)/s_iReLU(x/si​)=ReLU(x)/si​），中间的非线性不破坏抵消。净效果：层1每个输出通道被独立缩放，层2反向补偿，端到端输出不动——这就是”数学等价”。

⑤ 多层扩展与约束。三层共享通道（如 depthwise separable）推广为几何平均均摊；普通链式网络（如 VGG）对相邻层逐对迭代到收敛。适用需满足三个约束：

约束 说明

激活正缩放等变 ReLU / PReLU / 分段线性可用；ReLU6 需先换成 ReLU（论文实验即如此处理）
前置 BN 折叠 CLE 前先把 BatchNorm 折进权重，否则 range 统计不准

CLE 适用的算子

💡 说明：CLE 能否使用不取决于单个算子，而取决于相邻两层构成的”三明治”是否满足两个条件——两端都是线性映射（权重乘法，缩放矩阵 S 才能提出来相互抵消），且中间的激活正缩放等变（缩放才能穿过非线性不被破坏）。

适用的算子（可作为被均衡的”层”）。Conv 恰恰是 CLE 最主要的目标算子——论文核心实验对象 MobileNetV1/V2 全是卷积网络。

算子 是否适用 说明
Conv（常规卷积） ✅ 主力 权重 [Cout, Cin/g, kh, kw]，第一层按 Cout 轴缩放、第二层按 Cin 轴缩放，并在空间维 kh/kw 上广播
Depthwise Conv ✅ 逐通道独立、保持通道身份，正是 MobileNetV2 里 pointwise→depthwise→pointwise 三层均衡的中间层
ConvTranspose ✅ 反卷积同为线性映射，注意输入/输出通道轴与 Conv 相反
Gemm / FC / Linear ✅ 论文正文与附录 A 的推导即用两个全连接层完成

✅ Conv 关键细节（论文原文）：”In case of CNNs the scaling will be per channel and broadcast accordingly over the spatial dimensions.” 即缩放是逐通道的标量，对每个卷积核整个空间窗口（kh×kw）统一作用，卷积核空间结构不变，只是整体幅度按通道缩放。

会让 CLE 失效 / 不适用的情况。即便两端都是 Conv，下列情形也不能跨过去均衡：

  • 中间激活非正缩放等变：sigmoid、tanh、GELU、SiLU/Swish 都不满足 f(sx)=s·f(x)；ReLU6 因有固定截断点 6 也不严格等变（论文实验专门把 ReLU6 换成 ReLU 才做均衡）
  • 两层之间有分叉 / split：第一层输出被多层消费，或第二层输入来自多层 Concat 拼接，抵消关系被打破
  • 残差 Add：论文只在残差块内部的层间做 CLE，不跨越 skip-connection 的逐元素加
  • 非逐通道的通道混洗（如 channel shuffle）会破坏通道一一对应

📌 注意：对照 HMCT 实现。ActivationEqualization 更”专一”——其 match_pattern 明确要求下游算子是 Conv（activation_equalization.py:52），循环里 if next_op.op_type != "Conv": continue（第 80-82 行）跳过其余算子。即它只对”下一个算子是 Conv”生效，均衡该 Conv 权重（scaling_weight() 在 Cin 轴缩放）并转成 per-channel 校准节点；ConvTranspose、Gemm 不在其匹配范围。

高偏置吸收 Bias Absorption

当 si<1s_i < 1si​<1 时均衡会增大第一层 bias，可能扩大激活量化范围。用 r(Wx+b−c)=r(Wx+b)−cr(Wx+b-c) = r(Wx+b) - cr(Wx+b−c)=r(Wx+b)−c 把高偏置 c 吸收进下一层。为保持 data-free，用前一层 BN 参数假设激活服从正态分布，取 c=max⁡(0,β−3γ)c = \max(0, \beta - 3\gamma)c=max(0,β−3γ)，高斯假设下对 99.865% 的值成立。

💡 一句话：Bias Absorption 是给 CLE “擦屁股”的一步。CLE 为均衡权重 range，副作用是放大了某些通道的偏置、撑大了激活 range；本步用”ReLU 线性区可平移”的性质，把这部分高偏置无损转嫁到下一层，从而收窄激活量化范围。先均衡、再吸收，二者配套。

① 为什么需要（动机）。回忆 CLE 后第一层偏置变为 b^i(1)=bi(1)/si\hat{b}_i^{(1)} = b_i^{(1)} / s_ib^i(1)​=bi(1)​/si​。当某通道 si<1s_i < 1si​<1 时 1/si>11/s_i > 11/si​>1，该通道偏置被放大 → 激活值整体抬高 → 激活 range 变宽。而激活量化范围由 max 决定，range 越宽，8-bit 下每档越粗、激活量化误差越大。于是 CLE 把权重 range 均衡好了，却可能顺手把激活 range 搞坏，需要本步来修。

② 核心恒等式（凭什么能挪）。对 ReLU，当输入 y≥cy \geq cy≥c 且 c≥0c \geq 0c≥0 时：

ReLU⁡(y−c)=ReLU⁡(y)−c\operatorname{ReLU}(y - c) = \operatorname{ReLU}(y) - cReLU(y−c)=ReLU(y)−c

即只要 ReLU 的输入基本都落在线性区（都大于 c），”先减 c 再过 ReLU” 等于 “先过 ReLU 再减 c”，这给了偏置搬移的空间。

③ 吸收过程（输出严格不变）。设两层 h=ReLU⁡(W(1)x+b(1))h = \operatorname{ReLU}(W^{(1)}x + b^{(1)})h=ReLU(W(1)x+b(1))、y=W(2)h+b(2)y = W^{(2)}h + b^{(2)}y=W(2)h+b(2)，玩”加 c 减 c”：

对照得到三个更新，c 从第一层”流”进第二层偏置，端到端输出 y 不变：

参数 更新 含义
第一层偏置 b^(1)=b(1)−c\hat{b}^{(1)} = b^{(1)} - cb^(1)=b(1)−c 减小 c，激活 range 缩窄
第一层激活 h^=h−c\hat{h} = h - ch^=h−c 激活整体下移
第二层偏置 b^(2)=W(2)c+b(2)\hat{b}^{(2)} = W^{(2)}c + b^{(2)}b^(2)=W(2)c+b(2) c 被吸收进这里

✅ 偏置在硬件上通常用高精度（如 int32）存，不吃 8-bit 量化的亏，所以这笔”债”转到 bias 上几乎无损，而换来的是激活 range 收窄、激活量化更准。

④ 怎么 data-free 地选 c（关键技巧）。c 太大会有很多 y<cy < cy<c 使恒等式失效、输出被改坏；太小又没效果，且不能用数据统计。论文假设 ReLU 前激活服从正态分布，用前一层 BN 的 β、γ 当其均值与标准差（BN 参数是模型现成的，不算用数据），取 3σ 分位点：

c=max⁡(0, β−3γ)c = \max(0,\ \beta - 3\gamma)c=max(0, β−3γ)

β−3γ\beta - 3\gammaβ−3γ 是 0.135% 分位点，意味着 99.865% 的激活值都 ≥β−3γ\geq \beta - 3\gamma≥β−3γ，恒等式对绝大多数样本成立，只有极少尾部值引入微小误差。max(0, ·) 是保护：若 β−3γ<0\beta - 3\gamma < 0β−3γ<0（分布相当一部分贴近或低于 0），则 c=0 不吸收，避免破坏太多值。

📝 数值例子：某通道 ReLU 前分布 N(β=10, γ=1)，值几乎都在 [7,13]。取 c = max(0,10−3) = 7：吸收后第一层激活从 ~[7,13] 变为 ~[0,6]，激活量化范围从 ~13 砍到 ~6、误差近乎减半；被减的 7 以 W2·7 加进第二层偏置，输出不变。

⑤ 代价与收益。并非完全免费：那 0.135% 破坏恒等式的尾部值会让 FP32 精度轻微下降。论文 Table 1 中 MobileNetV2 的 FP32 从 71.70% 微降到 71.57%，但 INT8 从 69.91% 提升到 70.92%（+1% ↑），净收益明显为正。

📌 注意：本步（高偏置吸收）在 HMCT 中尚未实现，详见第五节 5.3 及第六节的落地建议。

量化偏差校正 Bias Correction

量化误差 ϵ=W~−W\epsilon = \tilde{W} - Wϵ=W~−W 会给输出带来偏移 E[ϵx]E[\epsilon x]E[ϵx]。只要从该层 bias 中减去期望误差，即可保持输出均值不变：

E[y]=E[y~]−E[ϵx]E[y] = E[\tilde{y}] - E[\epsilon x]E[y]=E[y~​]−E[ϵx]

关键的 data-free 技巧：用前一层 BN 参数（γ、β）配合 clipped normal distribution 闭式计算 E[x]E[x]E[x]，无需真实数据（若无 BN，也可用少量无标注数据经验估计，此时降为 Level 2）。

💡 一句话：量化误差并非零均值——权重量化会让每层输出的均值整体偏移，且逐层累积。Bias Correction 把这个系统性偏移算出来，从 bias 里直接减掉，让量化模型成为浮点模型的无偏估计。它针对的是论文”问题二”，与 CLE（针对”问题一”权重 range）互补。

① 问题：量化误差是有偏的。常见假设认为量化误差零均值、会在输出上相互抵消。但实际权重量化误差 ϵ=W~−W\epsilon = \tilde{W} - Wϵ=W~−W 在各输出通道上往往有非零均值，于是 y~=y+ϵx\tilde{y} = y + \epsilon xy~​=y+ϵx 的期望 E[ϵx]≠0E[\epsilon x] \neq 0E[ϵx]=0，输出均值被推偏。这个偏移会顺着网络逐层传播放大，depthwise 层每个输出通道只有 9 个权重，尤其严重。

② 校正原理。只要把期望误差从输出里减掉，就能恢复均值：

E[y]=E[y~]−E[ϵx]E[y] = E[\tilde{y}] - E[\epsilon x]E[y]=E[y~​]−E[ϵx]

由于 E[ϵx]E[\epsilon x]E[ϵx] 的形状与该层输出通道一致，实现上直接从该层 bias 中减去这个期望误差向量即可，零额外推理开销。卷积层同理（附录 B：误差在空间维求和后折进 bias）。

③ 两种算 E[εx] 的方式。核心是求期望输入 E[x]E[x]E[x]：

方式 级别 做法
解析法（BN + clipped normal） Level 1 data-free 用前一层 BN 的 β、γ 假设激活正态分布，经 ReLU 截断后用 clipped normal 闭式解求 E[x]，无需任何数据
经验法（附录 D） Level 2 无 BN 时，用少量无标注数据实测量化前后 pre-activation 均值之差，逐层校正
