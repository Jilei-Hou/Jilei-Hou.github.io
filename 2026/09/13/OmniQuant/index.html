OmniQuant：用少量可学习参数做低比特大模型量化

📌 一句话总结：OmniQuant 冻结大模型的原始权重，只学习两类量化参数：权重的裁剪强度（LWC），以及把激活量化难度转移到权重上的等价变换系数（LET）。它按 Transformer block 逐块做梯度优化，成本仍是 PTQ 级别（128 条校准样本，单张 A100 上 1–16 小时），在 W2A16、W3A16、W4A4 等低比特设置下明显好于 GPTQ、AWQ、SmoothQuant。学到的参数都能融合进权重，推理时没有额外开销。

适合读者：做大模型推理部署或模型压缩的同学。需要了解 INT 量化的 scale、zero-point 和 per-channel / per-token 等基本概念。

资料版本：arXiv 2308.13137 v3（2024-03-18）和官方仓库 OpenGVLab/OmniQuant。文中数字均摘自论文表格；困惑度（PPL）越低越好，准确率越高越好。

项目 内容

要解决的问题

PTQ 与 QAT 的取舍

大模型部署首先受限于显存和算力。以 GPT-3 为例，FP16 参数约需 350 GB 显存，至少要 5 张 A100-80G 才能推理。量化是降低这两项开销的主要手段，有两条路线：

路线 做法 成本示例 低比特表现
QAT（量化感知训练） 训练时模拟量化，更新全部权重 LLM-QAT：10 万条样本、数百 GPU 小时 精度较好，但在大模型上成本过高
PTQ（训练后量化） 不训练权重，用少量校准数据确定量化参数 GPTQ 量化 LLaMA-13B：128 条样本、单张 A100 约 1 小时 W4A16、W8A8 表现好；W2A16、W4A4 明显掉点

两类量化对象与记号

  • 仅权重量化（weight-only）：例如 W4A16，权重 4 bit，激活保持 16 bit。主要节省显存和访存带宽。
  • 权重-激活量化（weight-activation）：例如 W6A6、W4A4，权重和激活都量化，可以用低比特矩阵乘加速计算。
  • 记号：W3A16g128 表示 3 bit 权重、16 bit 激活，每 128 个权重为一组共享量化参数；不带 g 表示按输出通道（per-channel）量化。权重-激活量化中，激活按 token（per-token）量化。

现有 PTQ 方法在低比特下失效的原因

  1. **激活有离群通道。**少数通道的数值远大于其他通道（论文附录中 OPT-13B 某层激活的离群值约为 70），直接量化会让普通通道几乎分不到量化级别。SmoothQuant 和 Outlier Suppression+（下文简称 OS+）把量化难度从激活迁移到权重，但迁移强度是预先设定或网格搜索出来的。
  2. **权重量化误差同样关键。**SpQR、OWQ 用混合精度保留重要权重，AWQ 用网格搜索出的通道缩放来保护它们。

这些手工设定的参数在 W4A16、W8A8 下够用，到 W2A16、W4A4 就会明显掉点。论文要回答的问题是：能否在保持 PTQ 时间和数据成本的同时，达到 QAT 的精度。

核心思路

OmniQuant 的做法是：原始全精度权重不动，只把量化参数变成可学习的，并且一次只优化一个 Transformer block。QAT 要更新全部权重，OmniQuant 只学习裁剪强度和等价变换系数，所以数据和时间成本仍是 PTQ 级别。方法由三部分组成：

组成部分 针对的问题 学习的参数 推理时
LWC（Learnable Weight Clipping，可学习权重裁剪） 权重极值撑大量化范围 上、下界的裁剪强度 γ、β 只用来确定 scale 和零点，不留额外参数
LET（Learnable Equivalent Transformation，可学习等价变换） 激活中的离群通道 通道缩放 s、通道平移 δ、注意力中的缩放 s_a 融合进 LayerNorm 和线性层的权重、偏置
逐块量化误差最小化 整个模型联合优化的解空间太大 每次只优化一个 block 的 LWC、LET 参数 只是训练框架，不影响推理

图左侧是权重的处理链：冻结的全精度权重先经过等价变换（Transformation），再经过可学习裁剪（Clipping），最后量化。图中主体是 block 内的数据流：LayerNorm 之后、Q 与 K 相乘之前、输出投影之前、FFN 第一层之前各有一次等价变换，FFN 第二层（FC2）之前没有。

方法细节

逐块量化误差最小化

优化目标是让量化后的 block 输出尽量接近全精度 block 的输出：

arg⁡min⁡Θ1,Θ2∥F(W,X)−F(Qw(W;Θ1,Θ2), Qa(X,Θ2))∥\arg\min_{\Theta_1,\Theta_2}\left\|\mathcal{F}(\mathbf{W},\mathbf{X})-\mathcal{F}\left(Q_w(\mathbf{W};\Theta_1,\Theta_2),\,Q_a(\mathbf{X},\Theta_2)\right)\right\|argΘ1​,Θ2​min​∥F(W,X)−F(Qw​(W;Θ1​,Θ2​),Qa​(X,Θ2​))∥

  • F\mathcal{F}F 是一个 Transformer block 的映射，W\mathbf{W}W、X\mathbf{X}X 是全精度权重和激活，QwQ_wQw​、QaQ_aQa​ 是权重和激活的量化器。
  • Θ1={γ,β}\Theta_1=\{\gamma,\beta\}Θ1​={γ,β} 是 LWC 的参数，Θ2={s,δ,sa}\Theta_2=\{s,\delta,s_a\}Θ2​={s,δ,sa​} 是 LET 的参数。

选择逐块优化有两个原因。第一，LWC 和 LET 在同一个可微目标下联合优化，同一套流程既能做仅权重量化，也能做权重-激活量化。第二，需要优化的只有少量量化参数，比 AdaRound、BRECQ 这类要调整全部权重舍入的 PTQ 方法容易得多：LLaMA-2 全系列（7B–70B）在一张 A100-40G 上就能完成量化。

完整流程如下图，对应论文附录的算法 1：

  1. 初始化两路输入：Xfp=Xq=X\mathbf{X}_{fp}=\mathbf{X}_q=\mathbf{X}Xfp​=Xq​=X（校准数据）。
  2. 对第 i 个 block，先用全精度 block 算出目标输出 Xfp←Bi(Xfp)\mathbf{X}_{fp}\leftarrow\mathcal{B}_i(\mathbf{X}_{fp})Xfp​←Bi​(Xfp​)，再初始化 LWC 和 LET 参数。
  3. 训练若干 epoch：对 block 施加 LET 变换，用 LWC 量化权重，以 Xq\mathbf{X}_qXq​ 为输入做前向，计算与目标输出的 L2 误差，反向传播只更新 Θ1\Theta_1Θ1​、Θ2\Theta_2Θ2​。
  4. 训练结束后，把 LET 系数融合进相邻层，用学到的 γ、β 量化权重，得到这个 block 的最终低比特版本。
  5. 用量化好的 block 计算 Xq←Bi(Xq)\mathbf{X}_q\leftarrow\mathcal{B}_i(\mathbf{X}_q)Xq​←Bi​(Xq​)，作为下一个 block 的输入，直到最后一个 block。

量化路径的输入来自已经量化好的前几个 block，所以每个 block 的优化目标里已经包含了前面累积的误差。论文附录比较了各 block 的量化误差：基于网格搜索的 AWQ、OS+ 在深层的误差明显更大。

LWC：学习裁剪比例

权重里的极值会把量化范围撑大，大部分普通权重只能分到很少的量化级别。LWC 通过学习裁剪强度来收窄量化范围：

Wq=clamp(⌊Wh⌉+z, 0, 2N−1)\mathbf{W}_q=\mathrm{clamp}\left(\left\lfloor\frac{\mathbf{W}}{h}\right\rceil+z,\ 0,\ 2^N-1\right)Wq​=clamp(⌊hW​⌉+z, 0, 2N−1)

h=γmax⁡(W)−βmin⁡(W)2N−1,z=−⌊βmin⁡(W)h⌉h=\frac{\gamma\max(\mathbf{W})-\beta\min(\mathbf{W})}{2^N-1},\quad z=-\left\lfloor\frac{\beta\min(\mathbf{W})}{h}\right\rceilh=2N−1γmax(W)−βmin(W)​,z=−⌊hβmin(W)​⌉

  • N 是目标比特数，h 是量化步长（scale），z 是零点，⌊⋅⌉\lfloor\cdot\rceil⌊⋅⌉ 表示四舍五入。
  • γ、β ∈ [0, 1] 分别是上界和下界的裁剪强度，用 sigmoid 参数化。γ = β = 1 时退化为普通的 MinMax 量化。
  • 每个量化单元有一对 γ、β：按通道量化时是每个输出通道，分组量化时是每一组。官方代码把 sigmoid 的输入初始化为 4（sigmoid(4) ≈ 0.98），也就是从接近 MinMax 的状态开始学习。

PACT 直接学习裁剪阈值，LSQ 直接学习步长和零点；LWC 学的是相对 max / min 的比例。论文把 PACT 和 LSQ 换进 OmniQuant 的流程做了对比（LLaMA-7B，WikiText2 PPL，FP16 为 5.68）：

裁剪方法 W3A16 W4A4
MinMax（不裁剪） 25.73 14.49
PACT 6.95 18.25
LSQ 6.63 15.03
LWC 6.47 11.26

W4A4 下 LET 每次迭代都会改变权重分布（W~=s⊙W\tilde{\mathbf{W}}=s\odot\mathbf{W}W~=s⊙W），绝对阈值跟不上这种变化，PACT 甚至比不裁剪还差；相对比例则会随分布一起变化。另一个现象是比特越低裁剪越多：W3A16g128 中约 70% 的组裁剪强度大于 0.95，W2A16g128 中这一比例只有约 50%。

LET：可学习的等价变换

激活的离群值集中在固定的几个通道上。LET 用数学上等价的变换把这些通道压平，把难度转移到权重，再由 LWC 处理权重。它和 SmoothQuant 的区别在于：变换系数通过梯度学习，并且同时使用通道缩放和通道平移。

**线性层。**输入 X∈RT×Cin\mathbf{X}\in\mathbb{R}^{T\times C_{in}}X∈RT×Cin​，权重 W∈RCin×Cout\mathbf{W}\in\mathbb{R}^{C_{in}\times C_{out}}W∈RCin​×Cout​，偏置为 B\mathbf{B}B：

Y=XW+B=[(X−δ)⊘s]⋅[s⊙W]+[B+δW]=X~W~+B~\mathbf{Y}=\mathbf{X}\mathbf{W}+\mathbf{B}=\left[(\mathbf{X}-\delta)\oslash s\right]\cdot\left[s\odot\mathbf{W}\right]+\left[\mathbf{B}+\delta\mathbf{W}\right]=\tilde{\mathbf{X}}\tilde{\mathbf{W}}+\tilde{\mathbf{B}}Y=XW+B=[(X−δ)⊘s]⋅[s⊙W]+[B+δW]=X~W~+B~

Y=Qa(X~) Qw(W~)+B~\mathbf{Y}=Q_a(\tilde{\mathbf{X}})\,Q_w(\tilde{\mathbf{W}})+\tilde{\mathbf{B}}Y=Qa​(X~)Qw​(W~)+B~

  • s,δ∈R1×Cins,\delta\in\mathbb{R}^{1\times C_{in}}s,δ∈R1×Cin​ 是每个输入通道的缩放和平移，⊘ 和 ⊙ 是逐元素除法和乘法。
  • 平移 δ 把各通道的分布移到 0 附近；缩放 s 把离群通道压小，同时把对应的权重行放大。
  • QaQ_aQa​ 是普通 MinMax 量化器，QwQ_wQw​ 是带 LWC 的量化器。
  • 融合方式：X~\tilde{\mathbf{X}}X~ 中的 s、δ 吸收进前一个 LayerNorm 或线性层，W~\tilde{\mathbf{W}}W~ 中的 s 直接乘进 W，B~\tilde{\mathbf{B}}B~ 作为新的偏置。推理时不增加参数和计算。

**注意力。**为了把 Q、K 以及 KV cache 也量化到低比特，LET 对注意力打分再做一次通道缩放，然后用 MinMax 量化 Q~\tilde{\mathbf{Q}}Q~​、K~\tilde{\mathbf{K}}K~：

P=Softmax(QKT)=Softmax((Q⊘sa)(sa⊙KT))=Softmax(Q~K~T)\mathbf{P}=\mathrm{Softmax}(\mathbf{Q}\mathbf{K}^T)=\mathrm{Softmax}\left((\mathbf{Q}\oslash s_a)(s_a\odot\mathbf{K}^T)\right)=\mathrm{Softmax}(\tilde{\mathbf{Q}}\tilde{\mathbf{K}}^T)P=Softmax(QKT)=Softmax((Q⊘sa​)(sa​⊙KT))=Softmax(Q~​K~T)

s_a 可以吸收进 q_proj 和 k_proj 的权重。V 不单独变换，因为 [v_proj, out_proj] 这一组变换已经改变了它的通道分布。

**作用位置。**LET 用在四组位置上。论文在 LLaMA-7B W4A4 上逐一去掉某一组，看平均 PPL（WikiText2 与 C4 的平均）的变化，完整方法为 12.87：

  • [ln1, (q_proj, k_proj, v_proj)]：去掉后升到 19.87，影响最大，说明 LayerNorm 之后的离群值最严重。
  • [ln2, fc1]：去掉后为 14.47。
  • [Q, K]：去掉后为 13.34。
  • [v_proj, out_proj]：去掉后为 13.03。
  • FFN 第二层 fc2 不使用 LET：经过激活函数后特征很稀疏，学习时梯度不稳定。

和已有等价变换方法的区别（论文附录表 A1）：

方法 变换操作 作用位置 系数来源 适用场景

实验结果

  • 4 bit 分组量化时各方法差距在 0.2 以内，OmniQuant 略好。
  • 比特越低，差距越大。W3A16（按通道）下 OmniQuant 为 6.49，GPTQ 为 8.06，AWQ 为 11.88。
  • 2 bit 时 RTN 和 AWQ 完全失效，GPTQ 分组后为 22.10–44.01，OmniQuant 分组后为 8.90–9.72。
  • 模型越大越耐压：W2A16g128 下 LLaMA-1-65B 为 5.95（FP16 为 3.53），LLaMA-2-70B 为 6.55（FP16 为 3.31，GPTQ 在该设置下结果为 NAN）。

消融：两个组件各自的作用

逐个去掉组件后的 WikiText2 PPL：

设置 LLaMA-13B W4A4 LLaMA-13B W3A16 OPT-13B W4A4 OPT-13B W3A16
LWC + LET（完整方法） 10.87 5.65 11.65 10.87

  • W4A4 离不开 LET：去掉后 PPL 升到上千。
  • 仅权重量化主要靠 LWC。LLaMA-13B W3A16 去掉 LET 只从 5.65 变为 5.68，所以 LLaMA 的仅权重量化默认关闭 LET，以缩短训练时间。OPT 的权重离群值更多，W3A16 下只用 LET 就能把 PPL 从 4.6e3 降到 12.98。
  • 两者需要联合学习。LLaMA-7B W4A4 上，LET + LWC 的平均 PPL 为 12.87，SmoothQuant + LWC 为 15.80，LET + 网格搜索裁剪为 15.82；同时训练两者也好于交替训练。

指令微调模型

论文在 LLaMA-2-Chat 上做 W3A16g128 量化，用 Vicuna-Bench 的 80 个问题让 GPT-4 两两评判（每对按正反顺序各评一次，胜率不计平局）。7B-Chat 上 OmniQuant 对 RTN 的胜率为 80.3%，AWQ 对 RTN 为 69.4%，OmniQuant 与 AWQ 打平（50.0%）。13B-Chat 上 AWQ 不如 RTN（胜率 46.6%），OmniQuant 对 RTN 为 54.4%，对 AWQ 为 56.2%。

  • W4A16g128 在 7B 上的速度约为全精度的 1.9 倍（134.2 vs 69.2 token/s），权重显存从 12.6 GB 降到 3.8 GB。
  • LLaMA-65B 全精度在单张 80G 卡上放不下，W4A16g128 运行只需 41.0 GB。
  • MLC-LLM 当时对 INT3、INT2 的支持不够好，W3A16g128 反而比 W4A16g128 慢。
  • W6A6、W4A4 缺少现成的硬件支持，论文没有给出实测加速。

局限与适用场景

需要注意的局限

  • 校准耗时更长：约为 GPTQ 的 5 倍，LLaMA-65B 的 W4A4 量化需要约 14.4 小时。
  • 2 bit 仍有明显损失：LLaMA-2-7B W2A16 的 PPL 为 37.37（FP16 为 5.47），分组到 g64 也有 9.62。官方仓库说明 2 bit 模型只是端侧部署的极限探索，效果不如 3 bit。
  • W4A4 离无损还远：平均准确率比 FP16 低 10.8–12.0 个点，且没有实测加速数据。
  • 加速依赖推理框架的 kernel：论文的实测只覆盖仅权重量化。官方代码的 –real_quant 基于 AutoGPTQ kernel，README 注明这条路径下仅权重量化只能省显存，推理反而变慢。
  • 均匀 INT 量化的上限：与 SpQR、SqueezeLLM 这类混合精度或非均匀量化相比，仅权重量化的精度相当或略差（论文附录 A7）。好处是格式简单，并且同时支持权重-激活量化。
  • 部分设计是经验取舍：fc2 不做 LET；SoftMax 输出保持 16 bit。LLaMA-7B W4A4 上把 SoftMax 输出量化到 8 bit 损失很小（平均 PPL 从 12.87 到 12.91），到 4 bit 则升到 18.80。

什么时候值得用

  • 目标是 3 bit 及以下的仅权重量化，或 W6A6、W4A4 这类权重-激活量化。论文数据显示，这些设置下 OmniQuant 相对 GPTQ、AWQ、SmoothQuant 的优势最大。
  • 只做 W4A16g128 时，各方法差距不到 0.1（LLaMA-1-7B：OmniQuant 5.77，AWQ 5.81，GPTQ 5.85），校准更快的 GPTQ、AWQ 通常已经够用。
  • OmniQuant 只改变量化过程本身，论文认为它与 QLoRA 这类量化后做参数高效微调的方法互补。

开源实现与上手

官方仓库 OpenGVLab/OmniQuant（MIT 许可）提供：

  • OmniQuant 算法，支持 W4A16、W3A16、W2A16 和 W6A6、W4A4。
  • 预训练的量化参数（LLaMA-1/2、LLaMA-2-Chat、OPT、Falcon、Mixtral-8x7B），下载后即可生成量化权重，放在 Hugging Face。
  • 用 MLC-LLM 在 GPU 和手机上运行 W3A16g128 LLaMA-2-Chat（7B/13B）的示例 notebook。

💡 以下命令摘自官方 README，以 LLaMA-7B 为例，未在本文环境中实际运行。真实量化（–real_quant）还需要按 README 安装作者修复过的 AutoGPTQ。

常用参数：

参数 作用
--wbits / --abits 权重 / 激活的比特数
--group_size 权重分组大小；不设则按通道量化
--lwc / --let 启用 LWC / LET
--epochs 训练轮数（main.py 默认 10，README 示例用 20）；设为 0 并配合 --resume 可直接评测预训练参数
--nsamples 校准样本数，默认 128
--lwc_lr / --let_lr LWC / LET 的学习率，main.py 默认分别为 1e-2 和 5e-3，与论文正文写的 5e-3、1e-2 相反，复现时以所用脚本的设置为准
--resume 加载预训练的 OmniQuant 参数
--real_quant 真实量化，可以看到显存下降
--save_dir 保存量化后的模型
--eval_ppl / --tasks 评测困惑度 / 零样本任务
